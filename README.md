# Lakshita Singla Portfolio — V3

A formal, designer-led portfolio built with HTML, CSS and JavaScript.

## Publish
Upload `index.html`, `style.css`, `script.js`, `README.md`, and `assets/` to the root of the GitHub Pages repository.

Go to Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Before publishing, replace the LinkedIn `href="#"` in `index.html` with the real LinkedIn URL.
