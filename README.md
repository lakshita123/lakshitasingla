# Lakshita Singla — Portfolio

A premium, responsive single-page portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — page structure/content
- `style.css` — design system and responsive styling
- `script.js` — scroll progress + reveal animations
- `assets/Lakshita_Singla_Resume.pdf` — resume download

## GitHub Pages

1. Create a public repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Your site will appear at `https://YOURUSERNAME.github.io/`.

Before publishing, replace the placeholder email and LinkedIn URL in `index.html`.
